BlurScreen — 화면공유 블러 프로그램 (Windows용)
================================================

디스코드 등으로 화면을 공유할 때, 실제 화면 대신 블러 처리된
화면만 상대에게 보여주는 프로그램입니다. 원고·문서 유출 방지용.

[설치 — 처음 한 번만]

1. 압축을 풀고 BlurScreen.exe 를 원하는 폴더에 둡니다.
2. 처음 실행하면 파란색 "Windows의 PC 보호" (SmartScreen) 창이
   뜰 수 있습니다. 이때:
   "추가 정보" 클릭 → "실행" 버튼을 누르면 실행됩니다.
   (개인 제작 프로그램이라 인증서가 없어서 뜨는 정상적인 경고입니다)

[사용법]

1. BlurScreen 을 실행해 둡니다 (블러된 화면이 창에 보이면 정상)
2. 디스코드 → 화면 공유 → "애플리케이션" 탭 → Blur Screen 선택
3. 이후 평소처럼 작업하면, 상대에게는 블러 화면만 보입니다

* 공유 중에는 창을 최소화하지 말고, 다른 창 뒤에 가려두세요.
  (최소화하면 공유 화면이 멈출 수 있습니다)

[메뉴]

  작업 표시줄 오른쪽 알림 영역의 모니터 모양 아이콘 (안 보이면 ^ 버튼 안쪽)을 클릭하거나,
  블러 창을 마우스 오른쪽 버튼으로 클릭하면 메뉴가 열립니다.
  블러 강도·프레임 속도·모니터 선택, 화면 동결, 즉시 가림, 종료를
  모두 메뉴에서 할 수 있습니다.

[즉시 가림 — 어느 프로그램에서든]

  Ctrl+Alt+Shift+B
  누르면 블러 화면 대신 "보호 화면"만 나갑니다. 한 번 더 누르면 다시 시작.

[단축키 — BlurScreen 창을 클릭한 상태에서]

  1 / 2 / 3   블러 강도 약 / 중 / 강
  F           초당 프레임 5 → 10 → 15 전환
  M           모니터 전환 (모니터가 여러 대일 때)
  스페이스     화면 동결 / 해제

[요구 환경]  Windows 10 버전 1903 이상 (Windows 11 포함)
