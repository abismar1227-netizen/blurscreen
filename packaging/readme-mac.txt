BlurScreen — 화면공유 블러 프로그램 (macOS용)
================================================

디스코드 등으로 화면을 공유할 때, 실제 화면 대신 블러 처리된
화면만 상대에게 보여주는 프로그램입니다. 원고·문서 유출 방지용.

[설치 — 처음 한 번만]

1. BlurScreen.app 을 "응용 프로그램" 폴더로 옮깁니다.
2. 처음 열면 "확인되지 않은 개발자" 경고가 뜹니다. 이때:
   시스템 설정 → 개인정보 보호 및 보안 → 아래로 스크롤 →
   "그래도 열기" 버튼을 누르면 실행됩니다.
   (개인 제작 앱이라 애플 서명이 없어서 뜨는 정상적인 경고입니다)
3. "화면 기록" 권한 요청이 뜨면 허용해 주세요. 허용 후에는
   앱을 완전히 종료했다가 다시 실행해야 화면이 나옵니다.
   (직접 켜려면: 시스템 설정 → 개인정보 보호 및 보안 → 화면 기록
    → BlurScreen 켜기)

[사용법]

1. BlurScreen 을 실행해 둡니다 (블러된 화면이 창에 보이면 정상)
2. 디스코드 → 화면 공유 → "창" 탭 → Blur Screen 선택
3. 이후 평소처럼 작업하면, 상대에게는 블러 화면만 보입니다

* 공유 중에는 창을 최소화하지 말고, 다른 창 뒤에 가려두세요.
  (최소화하면 공유 화면이 멈출 수 있습니다)

[단축키 — BlurScreen 창을 클릭한 상태에서]

  1 / 2 / 3   블러 강도 약 / 중 / 강
  F           초당 프레임 5 → 10 → 15 전환
  M           모니터 전환 (모니터가 여러 대일 때)
  스페이스     화면 동결 (잠깐 완전히 가리고 싶을 때)

[요구 환경]  macOS 12.3 이상
